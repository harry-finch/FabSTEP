titre: "Vérifier le groupe circulaire sur la bride percée"
element: R-128
statut: a-faire
cree: 2026-11-20
par: agent
fait:
---

Dans le build de développement contenant R-128, ouvrir fixtures/repeated_patterns/flange.stl en millimètres. Préparer une correction facettisée, accepter Cylindre sur un trou de rayon 2 mm, puis rechercher les parois similaires. Le groupe circulaire doit sélectionner les cinq autres trous de même rayon. Désactiver puis réactiver le groupe. Vérifier le surlignage et l’absence de sélection sur le grand trou et l’emplacement vide.
